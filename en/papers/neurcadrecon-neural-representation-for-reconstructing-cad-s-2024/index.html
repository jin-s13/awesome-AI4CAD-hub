Deep Analysis

Innovations

  • Self-supervised neural SDF reconstruction of CAD models from low-quality unoriented point clouds
  • Developability loss term that encourages Gaussian curvature toward zero while preserving input point fidelity
  • Double-trough curve to tolerate non-zero Gaussian curvature at tip points
  • Dynamic sampling strategy for incomplete or too sparse input point clouds

Methodology

NeurCADRecon uses a self-supervised neural signed distance function with a loss that includes a developability term to enforce near-zero Gaussian curvature while maintaining fidelity to input points. It introduces a double-trough curve to handle tip points where Gaussian curvature is non-zero, and a dynamic sampling strategy for incomplete or sparse point clouds. The resulting neural SDF enables feature-aligned triangle mesh extraction and decomposition into smooth surface patches.

Key Results

The resulting neural SDFs clearly manifest sharp feature points and feature lines, enabling feature-aligned triangle mesh extraction and decomposition into smooth surface patches. Comprehensive comparisons with existing state-of-the-art methods show significant advantages in reconstructing faithful CAD shapes.

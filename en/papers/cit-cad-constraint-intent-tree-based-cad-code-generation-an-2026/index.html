Deep Analysis

Innovations

  • Introduces CIT-CAD, a framework that infers a Constraint Intent Tree (CIT) from input natural-language descriptions to explicitly represent intended entities, hierarchy, operations, and relations.
  • Uses the inferred CIT both to guide CAD code generation and to define expected constraints for verification.
  • Extracts actual constraints from generated CAD programs, compares them with expected constraints, and uses mismatches to localize and repair design violations.
  • First attempt to move text-to-CAD generation beyond rendered-geometry matching toward construction-aware synthesis, verification, and repair.

Methodology

CIT-CAD infers a Constraint Intent Tree from the input natural-language description, capturing intended entities, hierarchy, operations, and relations. This CIT guides CAD code generation and defines expected constraints. The framework then extracts actual constraints from the generated program, compares them with expected constraints, and uses mismatches to localize and repair design violations.

Key Results

Experiments show that the CIT-CAD framework improves CAD generation performance, with larger gains on more complex multi-entity designs.

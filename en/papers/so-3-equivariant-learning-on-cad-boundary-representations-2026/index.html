SO(3)-Equivariant Learning on CAD Boundary Representations

arXiv 2026 52.8 method

TLDR

SO3brep is an SO(3)-equivariant graph neural network for CAD B-reps that preserves relative face orientations and achieves high accuracy on rotated segmentation and classification benchmarks.

Reasoning

The paper presents a well-motivated equivariant architecture for B-rep learning, with strong theoretical grounding and empirical validation on rotated benchmarks with code released. Its scope is limited to face segmentation and classification, with no evidence for generative or reconstruction tasks and limited discussion of dataset diversity.

Deep Analysis

Innovations

  • Proposes SO3brep, an SO(3)-equivariant graph neural network operating on the B-rep face-adjacency graph.
  • Computes node features in local frames and maps them into a shared frame using Wigner D-matrices.
  • Uses Clebsch-Gordan tensor products to couple local features with directions between adjacent faces, preserving relative orientation during message passing.
  • Produces SE(3)-invariant outputs for boundary representation learning under arbitrary rotations.
  • Achieves highest accuracy with the fewest parameters compared to B-rep networks and equivariant point cloud networks.

Methodology

SO3brep is an SO(3)-equivariant graph neural network on the B-rep face-adjacency graph. Node features are computed in local frames and mapped into a shared frame by Wigner D-matrices, while Clebsch-Gordan tensor products couple these features with directions between adjacent faces to preserve relative orientation. It is evaluated on three face-segmentation and two classification benchmarks with randomly rotated test parts, compared against B-rep networks and equivariant point cloud networks.

Key Results

Across three face-segmentation and two classification benchmarks with randomly rotated test parts, SO3brep achieves the highest accuracy among the compared B-rep networks and equivariant point cloud networks, with the fewest parameters. Its advantage is largest with few labeled parts.
